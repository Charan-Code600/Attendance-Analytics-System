


# 📋 Attendance Analytics System

A Python tool to track and analyze student attendance using Pandas and CSV storage.

## Features

- ➕ Add attendance records (Student ID, Name, Date, Status)
- 👁️ View all attendance records
- 🎓 Student-wise attendance percentage
- ⚠️ Low attendance list (below 75%)
- 📅 Date-wise attendance trend
- 💾 Data saved permanently to CSV

## Requirements

pip install pandas

## How to Run

python attendance_analytics.py

## CSV Format

Data is automatically saved to `attendance.csv`:

StudentID,Name,Date,Status
S001,Aman,01-07-2026,Present
S002,Priya,01-07-2026,Absent

## Technologies Used

- Python
- Pandas
- CSV
- OS Module
